# Secure Notes frontend (React + Vite)

    npm install
    npm run dev       # http://localhost:5173
    npm run build     # output in dist/, deploy it to any static host

Backend URL: set `VITE_API_URL` in a `.env` file (see `.env.example`).
When deploying to Netlify/Vercel/Render Static Site, add the same variable in the host's settings.
